This project was inspired by the website of Awge, a marketing and audiovisual production company founded by American rapper A$AP Rocky. The Awge website is known for its unique and innovative design, which combines bold visual elements with an engaging user experience. The goal of this project is to create a personal portfolio that captures the essence of the Awge website design, using modern technologies such as Next.js, Three.js, and TailwindCSS to build a responsive and visually impressive interface.

Live: https://rafonso-dev-portfolio.vercel.app
